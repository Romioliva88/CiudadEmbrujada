# Ciudad Embrujada

Ciudad Embrujada es un videojuego 3D desarrollado en Unity como proyecto académico.

## Historia

Una bruja ha condenado la ciudad a una noche eterna. Para romper el hechizo, el jugador deberá explorar la ciudad, enfrentarse a las criaturas y encontrar los cuatro fragmentos de una antigua llave.

Además, deberá conseguir 1.000 Puntos de Luz derrotando enemigos. Al completar ambos objetivos aparecerá la antigua llave que permitirá encontrar la salida y romper la maldición.

## Cómo jugar

-flechas: mover al personaje.
- Mouse: mover la cámara.
- Utilizar la Espada de Luz para derrotar a las criaturas.
- Encontrar los 4 fragmentos de la llave.
- Conseguir 1.000 Puntos de Luz.
- Recoger la llave antigua.
- Encontrar la salida para romper la maldición.

## Características

- Juego en primera persona.
- Sistema de energía.
- Enemigos que detectan, persiguen y atacan al jugador.
- Sistema de Puntos de Luz.
- Fragmentos coleccionables.
- Sistema de llave y salida.
- Ciclo de noche y amanecer.
- Música ambiental.
- Pantalla de victoria y derrota.
